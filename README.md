### New Features in v1.0.8:
- **Multilingual Voice Recognition:** Full support for English, Urdu (ur-PK), Roman Urdu (transliterated), and Auto-detect language modes.
- **Active Category Personas:** Dedicated system prompt directives per assistant category: AI Assistant, Creative, Coding, Research, Productivity, General.
- **Live Web Search Toggle:** Real-time web search injection into AI responses, togglable from the chat controls bar.
- **Integrated Screenshot Capture:** One-click screenshot capture and attach to conversation context.
- **Persistent UI Preferences:** Active category and web search state saved and restored across sessions.
- **3-Day Update Grace Period:** Automatic update notification with 3-day grace period enforcement before mandatory lock.

### Update Policy:
Users on v1.0.7 will receive an immediate update notification. After 3 days, the app will lock until updated to v1.0.8.
