### New Features in v1.1.0

- **Intelligence & Reasoning Core:** intent understanding, ambiguity and missing-information detection, problem decomposition, comparative strategy evaluation, and structured action planning.
- **Adaptive Model Routing & Resilience:** task-complexity based model selection, provider health checks, retry/backoff recovery, verified fallback execution, and prompt-budget protection.
- **Unified Context & Verification:** conversation history, long-term memory, project knowledge, documents and RAG combined into one ranked context, with claims checked against evidence.
- **Agentic Tool Reasoning:** tools are invoked only when they add value; multi-step task state, specialist collaboration and verified procedure learning keep long tasks on track.
- **ARBATIQA Code Studio:** VS Code-style editor with line numbers, syntax colours, smart indentation, local multi-language execution, an embedded Chromium preview, standard input, and cloud fallback.
- **Expanded Windows Control:** brightness, volume, media keys, Wi-Fi, Bluetooth, airplane mode, power actions, display tools, personalisation, Settings pages, app control, and a risk-based permission engine.
- **Web Research Upgrade:** clean readable text extraction from public webpages plus stronger live search and evidence handling.
- **Security Hardening:** persistent login lockout with escalating cooldowns, URL safety checks, and SHA-256 verified update installers.
- **Refined Chromium Chat Surface:** smoother streaming, Markdown rendering, thinking state and conversation presentation.
- **Windows Version Metadata:** the packaged executable reports `FileVersion 1.1.0.0` and `ProductVersion 1.1.0`.
- **Mandatory Update Enforcement:** after the three-day grace period the app shell is locked to the update center until the verified installer runs.

### Update Policy

Users on **v1.0.9** receive an immediate in-app notification for v1.1.0. The update is optional for **3 days** from publication, then becomes mandatory. While mandatory, navigation, settings and chat are blocked; the user can download and install the verified update or exit the application.

This release is also prepared for **v1.1.1** (`minimum_supported_version = 1.1.0`), using the same notification and three-day enforcement flow.
